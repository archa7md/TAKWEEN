# TAKWEEN v2.7 — Architectural BIM Engine

## New
- Architectural BIM intermediate model.
- IfcSpace, IfcWall, IfcDoor, IfcWindow, IfcSlab, IfcStair.
- Level elevations and room placements.
- Preliminary wall, floor-finish and paint quantities.
- Stair quantity.
- Unified architectural BIM + BOQ dataset.
- API endpoint: `/projects/architectural-bim`.

## Position
This is a design-stage BIM engine. It is not yet a production Revit plugin,
a certified IFC exporter, tender BOQ, or Saudi code-compliance engine.

## Next
v2.8 should add real wall segmentation, external envelope walls,
door/window opening geometry, materials/property sets, and a proper IFC4
geometry writer with validated relationships.
